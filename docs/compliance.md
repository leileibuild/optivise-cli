# Compliance notes

This repository documents client behavior. It does not certify a regulatory posture for the hosted service or for a customer's deployment.

For an audit, record:

- CLI version and package checksum.
- The dry-run manifest, including file hashes and endpoint.
- The user approval event and the final command.
- The run ID, status response, and output checksums.
- The applicable Optivise privacy policy and service agreement.

Keep manifests and CSV files according to your organization's data-classification and retention rules. Do not place credentials in project files, URLs, or issue reports.
