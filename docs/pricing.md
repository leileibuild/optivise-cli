# Pricing model

Optivise CLI is free to install and use under the MIT License. The hosted solver is a separate service and may meter solver runtime, credits, or another plan-defined unit. This repository intentionally does not publish a price that could become stale or unapproved.

For current commercial terms, use the Optivise service pricing and agreement presented to your account. The CLI will show the server response for quota or billing errors without hiding them in a background process.
